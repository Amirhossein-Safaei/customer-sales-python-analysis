# Customer Sales Data Cleaning & Analysis Using Python

This project focuses on cleaning and analyzing a raw customer sales dataset using Python.

The goal of this project is to identify common data quality issues, clean the dataset, perform exploratory data analysis, visualize key business insights, and export a cleaned dataset for further reporting or dashboarding.

## Project Overview

In this project, I created a raw customer sales dataset with intentional data quality issues, then cleaned and analyzed it using Python.

The dataset included common real-world issues such as:

- Missing values
- Duplicate records
- Inconsistent text formatting
- Incorrect data types
- Mixed date formats
- Unclean categorical values

## Project Steps

- Imported Python libraries
- Created a raw customer sales dataset
- Explored dataset structure
- Checked missing values and duplicate records
- Cleaned inconsistent formatting
- Converted incorrect data types
- Created calculated columns
- Analyzed completed sales orders
- Visualized business insights
- Exported the cleaned dataset as a CSV file

## Analysis Included
